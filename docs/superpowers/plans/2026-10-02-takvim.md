# Takvim sayfası Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Terminalde yeni `TAKVİM` sayfası: temettü/sermaye artırımı, TCMB günleri ve bilanço sezonu tek listede, gün gün, her satırda KESİN ya da TAHMİNİ etiketiyle (sürüm 0.19.0).

**Architecture:** Saf kurallar `server/takvim.js`'te (çevrimdışı test edilir), ağ ve önbellek `server/takvim-kaynak.js`'te; tek uç nokta `GET /api/calendar`. Arayüz `market-view.js`'te yeni bir terminal sayfası (`calendar`), `app.js`'te hash yönlendirme. Metinleri istemci `t()` ile kurar; sunucu yalnız `type` ve `data` verir.

**Tech Stack:** Node 22.13+ (ESM, yerleşik `fetch`, `node:sqlite`), mevcut `server/*.js` modülleri, vanilya JS arayüz. Yeni bağımlılık yok.

**Spec:** [docs/superpowers/specs/2026-10-02-takvim-design.md](../specs/2026-10-02-takvim-design.md)

## Global Constraints

- Ürün adı her zaman küçük harfle: **kmy terminal**. Rakip adı hiçbir dosyada, çıktıda ya da notta geçmez.
- Kişisel veri git'e girmez (test verisi yalnız `/tmp` altındaki veritabanı kopyasında kalır).
- UI metinleri `t()` üzerinden, Türkçe kaynak metin anahtardır; İngilizce karşılıklar `web/js/lang/en/market.js`'e eklenir.
- Yeni bağımlılık yok; kaynaklar yalnız İş Yatırım (mevcut), KAP (mevcut) ve tcmb.gov.tr.
- Kesin ve tahmini bilgi her satırda **KESİN** / **TAHMİNİ** etiketiyle ayrılır; tahmini etiketin ipucu gerekçeyi taşır.
- TCMB tablosu biçimi değişirse **hata**, sessiz boş liste olmaz; çekilemezse son başarılı kayıt `stale` ile kullanılır.
- Pencere varsayılanı: `bugün − 7 gün` … `bugün + 60 gün`; en çok 366 gün. Tüm tarihler İstanbul takvim günüdür.
- Bilanço yalnız Listem/Portföyüm için hisse bazlı hesaplanır; `Tümü`'nde yalnız sembolsüz yasal son teslim üretilir.
- Yasal gün sayıları `[solo, konsolide]`: dönem 1 ve 3 → 30 / 40, dönem 2 → 50 / 60, dönem 4 → 60 / 70; hafta sonuna denk gelirse sonraki iş günü; resmî tatiller hesaba katılmaz.
- `npm test` zincirine canlı ağ gerektiren test girmez; `test/takvim.test.mjs` çevrimdışıdır.
- Repo komut/commit stili: Türkçe mesaj; her commit şu satırla biter: `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.
- Çalışma dalı `takvim`; birleştirme kararı kullanıcıya aittir (görev 4 sonunda sorulur).

## Review Focus

Spec'in söylemediği ama kullanıcıyı ilk ısıracak durumlar (en olasıdan başlayarak):

1. **KAP'ta yıllar sonra gelen düzeltme/yeniden sunum kayıtları** (ASELS 2025/1 dönemi, 25 Eylül 2026'da yayımlanmış): ilk açıklama sayılırsa "geçen yılın tarihi" yanlış çıkar. → Görev 1: `plausibleAnnouncements` testleri; Görev 2: 8 hissede "son teslimi aşan gözlem 0" doğrulaması.
2. **TCMB sayfa biçimi değişir** (sütun adı, boş tablo, kısa liste): sessizce boş takvim değil hata. → Görev 1: `parseTcmb` hata testleri.
3. **Hafta sonu ve artık yıl:** son teslim hafta sonuna denk gelirse pazartesi, beklenen gün hafta sonuna denk gelirse cuma, 29 Şubat → 28 Şubat. → Görev 1.
4. **Bir sembolde KAP hatası / izleme listesi ya da portföy boş:** sayfa çökmez; hata `warnings`'te, boş kapsamda TCMB olayları görünmeye devam eder (`emptyScope: true`). → Görev 2 canlı adımları.
5. **Gece yarısı ve gün grubu:** UTC 21:30 İstanbul'da ertesi gündür; "Bugün/Yarın" yanlış gruba düşmemeli. → Görev 1: `istanbulToday`, `groupKey` testleri.

```js
// Takvim: ayrıştırma ve kurallar. Çevrimdışı; KAP ve TCMB'ye gitmez.
import fs from 'node:fs';
import {
  trDate, parseTcmb, legalDeadline, expectedDate, candidatePeriods, bilancoEvents, marketSeasonEvents,
  corporateEvents, buildCalendar, defaultWindow, groupKey, istanbulToday, addDays, plausibleAnnouncements, LATE_GRACE_DAYS,
} from '../server/takvim.js';

let pass = 0, fail = 0;
function assert(name, cond, detail = '') {
  cond ? pass++ : fail++;
  console.log(`${cond ? 'OK  ' : 'FAIL'} ${name}${detail ? `: ${detail}` : ''}`);
}
const throws = (fn, re) => { try { fn(); return false; } catch (e) { return re.test(e.message); } };
const has = (list, type, date, symbol = null) => list.some((e) => e.type === type && e.date === date && e.symbol === symbol);
const FIX = fs.readFileSync(new URL('./fixtures/tcmb-takvim.html', import.meta.url), 'utf8');

// ── trDate ────────────────────────────────────────────────────────────────
assert('Türkçe ay adı: Şubat', trDate('12 Şubat 2026') === '2026-02-12');
assert('Türkçe ay adı: Ağustos', trDate('13 Ağustos 2026') === '2026-08-13');
assert('tek haneli gün', trDate('5 Mayıs 2026') === '2026-05-05');
assert('olmayan gün (30 Şubat) null', trDate('30 Şubat 2026') === null);
assert('bozuk metin / boş / nbsp null', trDate('bozuk') === null && trDate('') === null && trDate(' ') === null && trDate(null) === null);
assert('bilinmeyen ay null', trDate('12 Foo 2026') === null);

// ── parseTcmb (gerçek sayfa kopyası) ──────────────────────────────────────
const tc = parseTcmb(FIX);
assert('PPK karar ≥ 8', tc.filter((e) => e.type === 'ppk_karar').length >= 8, String(tc.filter((e) => e.type === 'ppk_karar').length));
assert('22 Ocak 2026 PPK kararı', has(tc, 'ppk_karar', '2026-01-22'));
assert('29 Ocak 2026 toplantı özeti', has(tc, 'ppk_ozet', '2026-01-29'));
assert('12 Şubat 2026 Enflasyon Raporu', has(tc, 'enflasyon_raporu', '2026-02-12'));
assert('22 Mayıs 2026 Finansal İstikrar Raporu', has(tc, 'fin_istikrar', '2026-05-22'));
assert('boş hücre olay üretmez (Ocak satırında istikrar raporu yok)', !tc.some((e) => e.type === 'fin_istikrar' && e.date < '2026-05-01'));
assert('TCMB olayları: kind tcmb, sembolsüz, kesin', tc.every((e) => e.kind === 'tcmb' && e.symbol === null && e.certainty === 'kesin'));
assert('2027 satırları da okunur', tc.some((e) => e.date.startsWith('2027-')));
assert('sütun adı değişirse hata', throws(() => parseTcmb(FIX.replace('Enflasyon Raporu', 'Başka Rapor')), /sütun/));
assert('tablo yoksa hata', throws(() => parseTcmb('<html><body>bakım</body></html>'), /bulunamadı/));
assert('boş girdi hata', throws(() => parseTcmb(''), /bulunamadı/));
const short = FIX.replace(/<tbody>[\s\S]*<\/tbody>/, '<tbody><tr><td>22 Ocak 2026</td><td>29 Ocak 2026</td><td></td><td></td></tr></tbody>');
assert('8\'den az PPK karar tarihi hata', throws(() => parseTcmb(short), /8/));

// ── legalDeadline ─────────────────────────────────────────────────────────
assert('3. çeyrek 2026 konsolide: 9 Kasım (pazartesi)', legalDeadline({ period: 3, year: 2026, consolidated: true }) === '2026-11-09');
assert('3. çeyrek 2026 solo: 30 Ekim (cuma)', legalDeadline({ period: 3, year: 2026, consolidated: false }) === '2026-10-30');
assert('3. çeyrek 2025 konsolide: 9 Kasım pazara denk gelir → pazartesi 10 Kasım', legalDeadline({ period: 3, year: 2025, consolidated: true }) === '2025-11-10');
assert('6 ay 2026 konsolide: 29 Ağustos cumartesi → 31 Ağustos', legalDeadline({ period: 2, year: 2026, consolidated: true }) === '2026-08-31');
assert('1. çeyrek 2026 konsolide: 10 Mayıs pazar → 11 Mayıs', legalDeadline({ period: 1, year: 2026, consolidated: true }) === '2026-05-11');
assert('yıllık 2025 konsolide: yıl sonu taşar → 11 Mart 2026', legalDeadline({ period: 4, year: 2025, consolidated: true }) === '2026-03-11');
assert('yıllık 2025 solo: 1 Mart pazar → 2 Mart', legalDeadline({ period: 4, year: 2025, consolidated: false }) === '2026-03-02');
assert('bilinmeyen dönem hata', throws(() => legalDeadline({ period: 5, year: 2026, consolidated: true }), /dönem/));
// Gözlenen gerçek açıklamalar (THYAO, konsolide) hesaplanan son teslimi aşmamalı: kuralın doğruluk kanıtı.
const OBS = [[3, 2025, '2025-11-07'], [4, 2025, '2026-03-04'], [1, 2026, '2026-04-29'], [2, 2026, '2026-08-05']];
assert('THYAO gözlemleri yasal son teslimi aşmaz', OBS.every(([p, y, d]) => d <= legalDeadline({ period: p, year: y, consolidated: true })));

// ── expectedDate ──────────────────────────────────────────────────────────
assert('geçen yıl cuma → bu yıl cumartesi → önceki iş günü', expectedDate('2025-11-07', '2026-11-09') === '2026-11-06');
assert('hafta içi aynen taşınır', expectedDate('2025-08-05', '2026-08-31') === '2026-08-05');
assert('29 Şubat → 28 Şubat', expectedDate('2024-02-29', '2025-03-11') === '2025-02-28');
assert('son teslimi geçmez', expectedDate('2025-11-10', '2026-11-09') === '2026-11-09');

// ── candidatePeriods ──────────────────────────────────────────────────────
const cp = candidatePeriods('2026-10-02');
assert('2 Ekim 2026: 2026/3 ve 2026/2', cp.length === 2 && cp[0].period === 3 && cp[0].year === 2026 && cp[1].period === 2 && cp[1].year === 2026);
const cp2 = candidatePeriods('2026-02-10');
assert('Şubat başı: 2025/4 ve 2025/3 (yıl sınırı)', cp2[0].period === 4 && cp2[0].year === 2025 && cp2[1].period === 3 && cp2[1].year === 2025);
const cp3 = candidatePeriods('2026-09-30');
assert('dönem sonu günü o dönem henüz aday değil', cp3[0].period === 2 && cp3[0].year === 2026);

// ── plausibleAnnouncements ────────────────────────────────────────────────
// KAP'ta yıllar sonra gelen düzeltme/yeniden sunum kayıtları ilk açıklama sayılmaz (ASELS 2025/1, 25 Eylül 2026 gibi).
const rec = (period, year, date) => ({ period, year, date });
const pl1 = plausibleAnnouncements([rec(1, 2025, '2026-09-25'), rec(3, 2025, '2025-11-04')], true);
assert('17 ay sonra gelen kayıt atılır, asıl açıklama kalır', pl1.length === 1 && pl1[0].period === 3);
assert('tam son teslim + 90 gün kalır', plausibleAnnouncements([rec(3, 2025, '2026-02-08')], true).length === 1 && LATE_GRACE_DAYS === 90);
assert('son teslim + 91 gün atılır', plausibleAnnouncements([rec(3, 2025, '2026-02-09')], true).length === 0);
assert('gerçekten geç ama makul açıklama kalır (son teslimden 20 gün sonra)', plausibleAnnouncements([rec(3, 2025, '2025-11-30')], true).length === 1);
assert('bilinmeyen dönem numarası atılır, çökmez', plausibleAnnouncements([rec(7, 2025, '2025-11-04'), rec(0, 2025, '2025-11-04')], true).length === 0);
assert('konsolide bilinmiyorsa (null) konsolide süre', plausibleAnnouncements([rec(3, 2025, '2025-11-04')], null).length === 1);
assert('boş girdi boş liste', plausibleAnnouncements([], true).length === 0);

// ── bilancoEvents ─────────────────────────────────────────────────────────
const T = '2026-10-02';
const ANN = [{ period: 3, year: 2025, date: '2025-11-07' }, { period: 2, year: 2026, date: '2026-08-05' }];
const b1 = bilancoEvents({ symbol: 'THYAO', today: T, announced: ANN, consolidated: true });
assert('açıklanmamış dönem: son teslim', has(b1, 'bilanco_son_teslim', '2026-11-09', 'THYAO'));
assert('açıklanmamış dönem: beklenen = geçen yılın günü (iş gününe çekilmiş)', has(b1, 'bilanco_beklenen', '2026-11-06', 'THYAO'));
assert('açıklanmış dönem: açıkladı (kesin, gerçek tarih)', b1.some((e) => e.type === 'bilanco_aciklandi' && e.date === '2026-08-05' && e.certainty === 'kesin'));
assert('açıklanmış dönem beklenen/son teslim üretmez', !b1.some((e) => ['bilanco_beklenen', 'bilanco_son_teslim'].includes(e.type) && e.data.period === 2));
assert('tahmini olaylar tahmini etiketli', b1.filter((e) => e.type !== 'bilanco_aciklandi').every((e) => e.certainty === 'tahmini'));
assert('beklenen olay geçen yıl tarihini ve son teslimi taşır', b1.find((e) => e.type === 'bilanco_beklenen').data.lastYear === '2025-11-07' && b1.find((e) => e.type === 'bilanco_beklenen').data.deadline === '2026-11-09');
const b2 = bilancoEvents({ symbol: 'YENI', today: T, announced: [{ period: 2, year: 2026, date: '2026-08-05' }], consolidated: true });
assert('geçen yıl kaydı yoksa yalnız son teslim', has(b2, 'bilanco_son_teslim', '2026-11-09', 'YENI') && !b2.some((e) => e.type === 'bilanco_beklenen'));
const b3 = bilancoEvents({ symbol: 'X', today: T, announced: [], consolidated: null });
assert('konsolide bilinmiyorsa konsolide süre ve assumed', b3.find((e) => e.type === 'bilanco_son_teslim' && e.data.period === 3).date === '2026-11-09' && b3.every((e) => e.type !== 'bilanco_son_teslim' || e.data.assumed === true));
const b4 = bilancoEvents({ symbol: 'X', today: T, announced: [], consolidated: false });
assert('solo şirket kısa süre (30 gün)', has(b4, 'bilanco_son_teslim', '2026-10-30', 'X') && b4.every((e) => e.data.assumed === false));
const b5 = bilancoEvents({ symbol: 'X', today: T, announced: [{ period: 3, year: 2026, date: '2026-10-01' }], consolidated: true });
assert('yeni açıklanan dönem: açıkladı, 3. dönem için beklenen yok', has(b5, 'bilanco_aciklandi', '2026-10-01', 'X') && !b5.some((e) => e.data.period === 3 && e.type !== 'bilanco_aciklandi'));

// ── marketSeasonEvents ────────────────────────────────────────────────────
const ms = marketSeasonEvents(T);
assert('Tümü: sembolsüz sezon son teslimleri', ms.length === 2 && ms.every((e) => e.symbol === null && e.data.market === true && e.type === 'bilanco_son_teslim'));
assert('Tümü: 3. dönem 9 Kasım, 2. dönem 31 Ağustos', has(ms, 'bilanco_son_teslim', '2026-11-09') && has(ms, 'bilanco_son_teslim', '2026-08-31'));

// ── corporateEvents ───────────────────────────────────────────────────────
const ce = corporateEvents([
  { code: 'AEFES', date: '2026-10-05', dpsGross: 0.1698, cashGrossPct: 16.98, bonusPct: 0, bonusDivPct: 0, rightsPct: 0 },
  { code: 'XYZ', date: '2026-10-06', dpsGross: 0, cashGrossPct: 0, bonusPct: 100, bonusDivPct: 0, rightsPct: 0 },
  { code: 'ABC', date: '2026-10-07', dpsGross: 1, cashGrossPct: 10, bonusPct: 20, bonusDivPct: 5, rightsPct: 50 },
  { code: 'NODATE', date: null, dpsGross: 1 },
  { code: 'EMPTY', date: '2026-10-08', dpsGross: 0, cashGrossPct: 0, bonusPct: 0, bonusDivPct: 0, rightsPct: 0 },
]);
assert('nakit temettü: temettu / temettu türü, brüt hisse başı', ce.some((e) => e.type === 'temettu' && e.symbol === 'AEFES' && e.kind === 'temettu' && e.data.dps === 0.1698));
assert('bedelsiz: sermaye grubu', ce.some((e) => e.type === 'bedelsiz' && e.symbol === 'XYZ' && e.kind === 'sermaye' && e.data.pct === 100));
assert('bir kayıttan dört olay', ce.filter((e) => e.symbol === 'ABC').length === 4);
```

```js
// Olay biçimi: { date: 'YYYY-MM-DD', type, kind, symbol|null, certainty: 'kesin'|'tahmini', data }

export const KINDS = ['temettu', 'sermaye', 'tcmb', 'bilanco'];
// Aynı günde gösterim sırası
export const TYPE_ORDER = ['ppk_karar', 'ppk_ozet', 'enflasyon_raporu', 'fin_istikrar', 'bilanco_aciklandi', 'bilanco_beklenen', 'bilanco_son_teslim', 'temettu', 'bedelsiz', 'bedelsiz_temettu', 'bedelli'];

// ── Tarih yardımcıları (hepsi UTC gün aritmetiği; "YYYY-MM-DD" metni takvim günüdür) ──
const toMs = (d) => Date.parse(`${d}T00:00:00Z`);
const isoOf = (ms) => new Date(ms).toISOString().slice(0, 10);
export const addDays = (d, n) => isoOf(toMs(d) + n * 86400_000);
export const weekday = (d) => new Date(toMs(d)).getUTCDay(); // 0 pazar … 6 cumartesi
const nextBusiness = (d) => { while (weekday(d) === 0 || weekday(d) === 6) d = addDays(d, 1); return d; };
const prevBusiness = (d) => { while (weekday(d) === 0 || weekday(d) === 6) d = addDays(d, -1); return d; };
const validIso = (d) => typeof d === 'string' && /^\d{4}-\d{2}-\d{2}$/.test(d) && Number.isFinite(toMs(d)) && isoOf(toMs(d)) === d;

/** İstanbul takvim günü. */
export function istanbulToday(nowMs = Date.now()) {
  const p = Object.fromEntries(new Intl.DateTimeFormat('en-GB', { timeZone: 'Europe/Istanbul', year: 'numeric', month: '2-digit', day: '2-digit' }).formatToParts(new Date(nowMs)).map((x) => [x.type, x.value]));
  return `${p.year}-${p.month}-${p.day}`;
}

/** "22 Ocak 2026" → "2026-01-22"; geçersiz ya da boşsa null. */
export function trDate(text) {
  const m = /^(\d{1,2}) (\S+) (\d{4})$/.exec(String(text ?? '').trim());
  if (!m) return null;
  const mi = MONTHS.indexOf(m[2]);
  if (mi < 0) return null;
  const iso = `${m[3]}-${String(mi + 1).padStart(2, '0')}-${m[1].padStart(2, '0')}`;
  return validIso(iso) ? iso : null;
}

const ev = (date, type, kind, symbol, certainty, data = {}) => ({ date, type, kind, symbol, certainty, data });

// ── TCMB ────────────────────────────────────────────────────────────────
const TCMB_COLS = [['ppk_karar', /karar/], ['ppk_ozet', /özet/], ['enflasyon_raporu', /enflasyon raporu/], ['fin_istikrar', /istikrar/]];
const cellText = (h) => h.replace(/<[^>]+>/g, ' ').replace(/&nbsp;| /g, ' ').replace(/\s+/g, ' ').trim();

/**
 * tcmb.gov.tr takvim sayfasındaki tabloyu olaylara çevirir. Hücre bazlı okunur (boş hücreler korunur).
 * Biçim değişirse (tablo yok, sütun adları değişmiş, 8'den az PPK karar tarihi) hata fırlatır;
 * sessizce boş liste dönmez.
 */
export function parseTcmb(html) {
  const table = /<table[\s\S]*?<\/table>/i.exec(String(html ?? ''))?.[0];
  if (!table) throw new Error('TCMB takvim tablosu bulunamadı');
  const rows = [...table.matchAll(/<tr[\s\S]*?<\/tr>/gi)].map((r) => [...r[0].matchAll(/<t[dh][\s\S]*?<\/t[dh]>/gi)].map((c) => cellText(c[0])));
  const head = (rows[0] || []).map((x) => x.toLocaleLowerCase('tr'));
  if (head.length < 4 || !TCMB_COLS.every(([, re], i) => re.test(head[i]))) throw new Error('TCMB takvim sütunları değişmiş');
  const out = [];
  for (const cells of rows.slice(1)) {
    TCMB_COLS.forEach(([type], i) => {
      const date = trDate(cells[i]);
      if (date) out.push(ev(date, type, 'tcmb', null, 'kesin'));
    });
  }
  if (out.filter((e) => e.type === 'ppk_karar').length < 8) throw new Error('TCMB takvimi beklenenden kısa (8\'den az PPK karar tarihi)');
  return out;
}

// ── Bilanço ─────────────────────────────────────────────────────────────
const PERIOD_END = { 1: '03-31', 2: '06-30', 3: '09-30', 4: '12-31' };
// SPK II-14.1: [konsolide olmayan, konsolide] yasal gün sayısı (3 ve 9 aylık 30/40, 6 aylık 50/60, yıllık 60/70)
const LEGAL_DAYS = { 1: [30, 40], 2: [50, 60], 3: [30, 40], 4: [60, 70] };

export const periodEnd = (period, year) => {
  if (!PERIOD_END[period]) throw new Error(`Bilinmeyen dönem: ${period}`);
  return `${year}-${PERIOD_END[period]}`;
};

/** Yasal son teslim: dönem sonu + yasal gün; hafta sonuna denk gelirse sonraki iş günü (resmî tatiller hesaba katılmaz). */
export function legalDeadline({ period, year, consolidated }) {
  const days = LEGAL_DAYS[period];
  if (!days) throw new Error(`Bilinmeyen dönem: ${period}`);
  return nextBusiness(addDays(periodEnd(period, year), days[consolidated ? 1 : 0]));
}

/** Geçen yılın açıklama gününü bir yıl ileri taşır (29 Şubat → 28 Şubat); hafta sonuna denk gelirse önceki iş günü; son teslimi geçmez. */
export function expectedDate(lastYearIso, deadlineIso) {
  const [y, m, d] = lastYearIso.split('-').map(Number);
  let ms = Date.UTC(y + 1, m - 1, d);
  if (new Date(ms).getUTCMonth() !== m - 1) ms = Date.UTC(y + 1, m - 1, d - 1);
  const exp = prevBusiness(isoOf(ms));
  return exp > deadlineIso ? deadlineIso : exp;
}

/** Bugünden önce biten son iki dönem (yeniden eskiye). */
export function candidatePeriods(today) {
  const y = Number(today.slice(0, 4));
  const all = [];
  for (const year of [y - 1, y]) for (const period of [1, 2, 3, 4]) all.push({ period, year, end: periodEnd(period, year) });
  return all.filter((c) => c.end < today).sort((a, b) => b.end.localeCompare(a.end)).slice(0, 2);
}

/** Yasal son teslimden bu kadar gün sonra gelen KAP kaydı ilk açıklama sayılmaz. */
export const LATE_GRACE_DAYS = 90;

/**
 * KAP'ta yıllar sonra gelen düzeltme/yeniden sunum kayıtlarını (ör. 2025/1 dönemi için 2026 Eylül'de yayımlanan)
 * ilk açıklama saymamak için süzer; "geçen yılın tarihi" olarak yanlış kullanılmasın. Bilinmeyen dönem numarası atılır.
 */
export function plausibleAnnouncements(records, consolidated) {
  return records.filter((r) => r.period >= 1 && r.period <= 4
    && r.date <= addDays(legalDeadline({ period: r.period, year: r.year, consolidated: consolidated ?? true }), LATE_GRACE_DAYS));
}

/**
 * Bir hissenin bilanço olayları.
 *  announced:    [{ period, year, date }] KAP'tan, dönem başına en erken açıklama günü
 *  consolidated: true | false | null (hiç kayıt yoksa null → konsolide süre varsayılır, data.assumed)
 */
export function bilancoEvents({ symbol, today, announced = [], consolidated = null }) {
  const out = [];
  for (const { period, year } of candidatePeriods(today)) {
    const rec = announced.find((a) => a.period === period && a.year === year);
    if (rec) { out.push(ev(rec.date, 'bilanco_aciklandi', 'bilanco', symbol, 'kesin', { period, year })); continue; }
    const assumed = consolidated == null;
    const cons = consolidated ?? true;
    const deadline = legalDeadline({ period, year, consolidated: cons });
    out.push(ev(deadline, 'bilanco_son_teslim', 'bilanco', symbol, 'tahmini', { period, year, consolidated: cons, assumed }));
    const last = announced.find((a) => a.period === period && a.year === year - 1);
    if (last) out.push(ev(expectedDate(last.date, deadline), 'bilanco_beklenen', 'bilanco', symbol, 'tahmini', { period, year, lastYear: last.date, deadline }));
  }
  return out;
}

/** "Tümü" kapsamı: hisse bazlı değil, her aday dönem için tek sembolsüz yasal son teslim (konsolide süre). */
export function marketSeasonEvents(today) {
  return candidatePeriods(today).map(({ period, year }) =>
    ev(legalDeadline({ period, year, consolidated: true }), 'bilanco_son_teslim', 'bilanco', null, 'tahmini', { period, year, consolidated: true, assumed: false, market: true }));
}

/** universe.corporateActions kayıtlarını olaylara ayırır (bir kayıttan birden çok olay çıkabilir). */
export function corporateEvents(actions) {
  const out = [];
  for (const a of actions) {
    if (!a.date) continue;
    if (a.dpsGross > 0 || a.cashGrossPct > 0) out.push(ev(a.date, 'temettu', 'temettu', a.code, 'kesin', { dps: a.dpsGross || null, grossPct: a.cashGrossPct || null }));
    if (a.bonusPct > 0) out.push(ev(a.date, 'bedelsiz', 'sermaye', a.code, 'kesin', { pct: a.bonusPct }));
    if (a.bonusDivPct > 0) out.push(ev(a.date, 'bedelsiz_temettu', 'sermaye', a.code, 'kesin', { pct: a.bonusDivPct }));
    if (a.rightsPct > 0) out.push(ev(a.date, 'bedelli', 'sermaye', a.code, 'kesin', { pct: a.rightsPct }));
  }
  return out;
}

export const defaultWindow = (today) => ({ from: addDays(today, -7), to: addDays(today, 60) });

/** Pencere [from, to] (iki uç dahil) ve tür süzgeciyle sıralı, tekilleştirilmiş liste. */
export function buildCalendar({ from, to, events, kinds = null }) {
  if (!validIso(from) || !validIso(to)) throw new Error('Tarih YYYY-AA-GG biçiminde olmalı');
  if (from > to) throw new Error('Başlangıç tarihi bitişten sonra olamaz');
  if ((toMs(to) - toMs(from)) / 86400_000 > 366) throw new Error('Pencere en çok 366 gün olabilir');
  const want = new Set(kinds && kinds.length ? kinds : KINDS);
  const seen = new Set();
  const rank = (t) => { const i = TYPE_ORDER.indexOf(t); return i < 0 ? TYPE_ORDER.length : i; };
  return events
    .filter((e) => e.date >= from && e.date <= to && want.has(e.kind))
    .filter((e) => { const k = `${e.date}|${e.type}|${e.symbol ?? ''}`; if (seen.has(k)) return false; seen.add(k); return true; })
    .sort((a, b) => a.date.localeCompare(b.date) || rank(a.type) - rank(b.type) || String(a.symbol ?? '').localeCompare(String(b.symbol ?? '')));
}

/** Gün grubu: son_gunler (önceki 7 gün) · bugun · yarin · hafta (2–6 gün sonra) · tarih. */
export function groupKey(date, today) {
  if (date < today) return 'son_gunler';
  if (date === today) return 'bugun';
  if (date === addDays(today, 1)) return 'yarin';
  if (date <= addDays(today, 6)) return 'hafta';
  return 'tarih';
}
```

```js
// Takvim: ağ ve önbellek katmanı. Olay kuralları takvim.js'tedir (saf, çevrimdışı test edilir).
// Sağlayıcılar: TCMB (tcmb.gov.tr tablosu), temettü/sermaye artırımı (İş Yatırım, universe.js), bilanço (KAP).
import { cacheGet, cachePut } from './db.js';
import * as universe from './universe.js';
import * as kap from './kap.js';
import * as store from './store.js';
import * as pf from './portfolio.js';
import { normalize, isBist } from './market.js';
import { parseTcmb, corporateEvents, bilancoEvents, plausibleAnnouncements, marketSeasonEvents, buildCalendar, defaultWindow, istanbulToday, KINDS } from './takvim.js';

const TCMB_URL = 'https://www.tcmb.gov.tr/wps/wcm/connect/TR/TCMB+TR/Main+Menu/Duyurular/Takvim';
const DAY = 86400_000;

/** TCMB olayları: günde bir çekilir; çekilemezse son başarılı kayıt (30 güne kadar) `stale` ile kullanılır. */
export async function tcmbEvents() {
  const hit = cacheGet('takvim:tcmb', DAY);
  if (hit) return { events: hit.events, stale: false };
  try {
    const res = await fetch(TCMB_URL, { headers: { 'User-Agent': 'Mozilla/5.0' }, signal: AbortSignal.timeout(20_000) });
    if (!res.ok) throw new Error(`TCMB HTTP ${res.status}`);
    const events = parseTcmb(await res.text());
    cachePut('takvim:tcmb', { events });
    return { events, stale: false };
  } catch (e) {
    const old = cacheGet('takvim:tcmb', 30 * DAY);
    if (old) return { events: old.events, stale: true, error: e.message };
    return { events: [], stale: false, error: e.message };
  }
}

/**
 * Bir sembolün son 365 gündeki finansal rapor açıklamaları (KAP; sembol başına 24 saat önbellek).
 * Dönem (1 = 3 ay … 4 = yıllık) başına EN ERKEN gün alınır (düzeltme bildirimleri sonradan gelir).
 * consolidated: bildirim başlıklarında "Konsolide" geçiyorsa true; kayıt var ama geçmiyorsa false; hiç kayıt yoksa null.
 */
export async function announcedFor(symbol) {
  const key = `takvim:fr:${symbol}`;
  const hit = cacheGet(key, DAY);
  if (hit) return hit;
  const items = await kap.companyDisclosures(symbol, 365);
  const fr = items.filter((x) => x.cls === 'FR' && x.period && x.year);
  const best = new Map();
  for (const x of fr) {
    const k = `${x.period}/${x.year}`;
    const date = String(x.date).slice(0, 10); // KAP tarihi +03:00 ofsetli: ilk 10 karakter İstanbul günüdür
    if (!best.has(k) || date < best.get(k).date) best.set(k, { period: Number(x.period), year: Number(x.year), date });
  }
  const consolidated = fr.length ? fr.some((x) => /konsolide/i.test(x.subject || '')) : null;
  const out = { announced: plausibleAnnouncements([...best.values()], consolidated), consolidated };
  cachePut(key, out);
  return out;
}

async function pool(items, n, fn) {
  let i = 0;
  await Promise.all(Array.from({ length: Math.min(n, items.length) }, async () => { while (i < items.length) await fn(items[i++]); }));
}

/** Takvim yanıtı. Sembole bağlı olaylar kapsamla (listem/portföyüm) sınırlanır; TCMB olayları her kapsamda gelir. `mine`: listedeki ve portföydeki BIST sembolleri (arayüz işaretlemesi için). */
export async function calendar({ scope = 'portfolio', from = null, to = null, kinds = null, now = Date.now() } = {}) {
  if (!['watchlist', 'portfolio', 'all'].includes(scope)) throw new Error('Geçersiz kapsam');
  if (kinds && kinds.some((k) => !KINDS.includes(k))) throw new Error('Geçersiz olay türü');
  const today = istanbulToday(now);
  const w = defaultWindow(today);
  from = from || w.from;
  to = to || w.to;

  const bist = (list) => [...new Set(list.map(normalize))].filter((s) => s && isBist(s));
  const mine = { watchlist: bist(store.watchlist()), portfolio: bist(pf.computeLedger().holdings.map((h) => h.symbol)) };
  const symbols = scope === 'all' ? null : mine[scope];

  const events = [], warnings = [], stale = [];

  const tc = await tcmbEvents();
  events.push(...tc.events);
  if (tc.stale) stale.push('tcmb');
  if (tc.error) warnings.push({ source: 'tcmb', message: tc.error });

  await universe.refresh().catch(() => {});
  events.push(...corporateEvents(await universe.corporateActions({ symbols, from, to })));

  if (symbols) {
    await pool(symbols, 2, async (symbol) => {
      try {
        const { announced, consolidated } = await announcedFor(symbol);
        events.push(...bilancoEvents({ symbol, today, announced, consolidated }));
      } catch (e) { warnings.push({ source: 'kap', message: `${symbol}: ${e.message}` }); }
    });
  } else events.push(...marketSeasonEvents(today));

  return { today, from, to, scope, events: buildCalendar({ from, to, events, kinds }), warnings, stale, emptyScope: !!symbols && symbols.length === 0, mine: [...new Set([...mine.watchlist, ...mine.portfolio])] };
}
```
