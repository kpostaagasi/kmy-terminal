# Katkı rehberi

Teşekkürler! kmy terminal ücretsiz bir beta ve açık kaynak olmaya hazırlanıyor.

- **Sorun/öneri:** GitHub Issues. Hata bildiriminde sürüm, işletim sistemi ve adımları yazın; **portföy, kimlik veya API anahtarı paylaşmayın**.
- **Geliştirme:** Node ≥ 22.13. `npm install` · `npm start` · `npm test`. Değişikliğinizle ilgili test ekleyin.
- **PR:** küçük ve tek konulu olsun; `main`'e açın, açıklamada neyi neden değiştirdiğinizi yazın, `CHANGELOG.md`'ye satır ekleyin.
- **Dil kuralları:** UI'da "AL/SAT" yerine "hedefe göre artır/azalt"; hedef fiyat içeren çıktılarda "Bu bir yatırım tavsiyesi değildir." Bkz. `CONTEXT.md`.
- **Veri kaynakları:** içerik kopyalayan (rapor metni, ücretli veri) katkılar kabul edilmez; yalnız link/başlık.
- **Lisans:** katkılarınız projenin lisansı altında yayımlanır (lisans seçimi beklemede; CLA/DCO gerekebilir).
